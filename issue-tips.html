附 🧭 通用排障三板斧 + 状态速查表 不管什么问题先跑三条命令,80% 的答案就在输出里;Pod 状态对号入座

不管什么问题,先跑这三条,80% 的答案就在输出里:

kubectl describe pod <pod> -n <ns>                    # Events 区 = 病历本
kubectl logs <pod> -n <ns> --tail=100 --previous   # 应用自己的报错(--previous 看上一次崩溃)
kubectl get events -A --sort-by=.lastTimestamp | tail -20   # 全集群最近发生了什么

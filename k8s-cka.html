C1考试概览:17 道题都考什么?

CKA(Certified Kubernetes Administrator)是 CNCF / Linux Foundation 推出的基于实操的认证 —— 不是选择题,而是要求你在真实的 Kubernetes 集群环境中解决实际问题:考试通常包含 17 道题目,限时 2 小时完成。

项说明
认证机构CNCF / Linux Foundation
考试形式全程实操(命令行 + 真实多节点集群),无选择题
题量 / 时长17 题 / 2 小时(平均每题约 7 分钟)
考试环境内嵌终端 + 多个集群(每题可能要求切换 context)
题目形态题库变体:命名空间、标签、版本号等参数每次变化,核心知识点和解题思路不变

五大领域与权重(2025 课程大纲)

领域权重分布
🔴 故障排查30%
🔵 集群架构、安装与配置25%
🟢 服务与网络20%
🟣 工作负载与调度15%
🟠 存储10%

了解这个分布能帮你更好地分配复习精力:故障排查(30%)+ 集群架构(25%)两项占一半以上,是备考主战场。

💡 关键提示:17 道题是题库变体 —— 具体参数(命名空间、标签、版本号)每次考试都会变化,但核心知识点和解题思路不变。切勿死记硬背命令,务必理解原理并熟练操作。

C2题目 1:Kubernetes 集群升级 ★已精讲

这正是集群架构领域的核心考点。考试会要求你将现有集群(如 1.31.0)的主节点升级到指定新版本(如 1.31.1)。

⚠️ 核心原则:控制平面优先,逐个升级。绝对不能先升级工作节点,必须遵循 控制平面 → 工作节点(逐个) 的顺序。考试通常只要求升级主节点。

升级流程总览(10 步)

①切上下文 ─▶ ②排水master ─▶ ③SSH+提权 ─▶ ④解锁版本包 ─▶ ⑤装指定版本包
                                                              │
⑩验证版本 ◀─ ⑨解除排水 ◀─ ⑧重启kubelet ◀─ ⑦重新锁定包 ◀─ ⑥升级控制平面

每步详细命令与说明(考试必练)

# ────────── 1. 切换集群上下文 ──────────
# 考试环境有多个集群,必须先切换到题目要求的集群(如 xk8s)
kubectl config use-context xk8s

# ────────── 2. 排水主节点 ──────────
# 将节点标记为不可调度,并驱逐其上的 Pod(除 DaemonSet 管理的 Pod 外)
kubectl drain master --ignore-daemonsets

# ────────── 3. 登录主节点并提权 ──────────
# 使用题目提供的 SSH 命令登录,并切换到 root 权限
ssh master
sudo -i

# ────────── 4. 解锁版本包 ──────────
# Ubuntu 系统使用 apt-mark 来管理包版本
apt-mark unhold kubeadm kubelet kubectl

# ────────── 5. 更新软件源并安装指定版本 ──────────
# 确保安装与目标版本匹配的包(版本号必须精确到 -1.1 这种完整后缀)
apt-get update
apt-get install kubeadm=1.31.1-1.1 kubelet=1.31.1-1.1 kubectl=1.31.1-1.1

# ────────── 6. 升级控制平面组件(★核心步骤)──────────
# --etcd-upgrade=false 表示不升级 etcd
kubeadm upgrade apply v1.31.1 --etcd-upgrade=false

# ────────── 7. 重新锁定版本包 ──────────
# 防止后续意外升级
apt-mark hold kubeadm kubelet kubectl

# ────────── 8. 重启 kubelet 服务 ──────────
# 使新的 kubelet 配置生效
systemctl daemon-reload
systemctl restart kubelet

# ────────── 9. 退出主节点并解除排水 ──────────
# 返回到你的考试终端,解除节点的不可调度状态
exit
kubectl uncordon master

# ────────── 10. 最终验证 ──────────
# 检查节点状态,确认版本已更新且节点 Ready
kubectl get nodes
# NAME     STATUS   ROLES           AGE   VERSION
# master   Ready    control-plane   10d   v1.31.1   ← 版本已更新 + Ready 即完成
⚠️ 注意:考试环境可能使用不同的包管理器(如 yum)或 Kubernetes 发行版,但核心逻辑和顺序不变 —— 切上下文 → drain → 升级 kubeadm/kubelet/kubectl 三件套 → kubeadm upgrade apply → uncordon → 验证。务必在模拟环境中反复练习。
💡 两个高频丢分点:① apt-get install 忘写精确版本号后缀(=1.31.1-1.1)装成最新版,直接污染集群;② 升级完忘了 kubectl uncordon,节点一直 NotReady/SchedulingDisabled —— 最后 kubectl get nodes 看一眼 STATUS 列再交卷。

🎯 备考建议(5 条)

  • 搭建练习环境:使用 kind、minikube 或 kubeadm 快速搭建本地多节点集群,所有命令都在真实环境中敲一遍;
  • 官方文档为主:将 Kubernetes 官方文档作为你的"圣经",不要依赖任何第三方题库答案;
  • 模拟考试是关键:购买 CKA 考试通常会附赠 killer.sh 模拟器权限,务必在考前完成多次模拟,适应节奏和界面;
  • 时间管理:2 小时 17 题,平均每题 7 分钟 —— 遇到卡壳的题先标记跳过,最后回头处理;
  • 注意细节:考试要求精确,如命名空间名称、标签、资源命名等,写错可能导致 0 分。
